### PROYECTO: REGISTRO DE USUARIO E INICIO DE SESIÓN EN UNA APP MÓVIL(REUSISAM)

_Descripción:_

Un proyecto de Android basado en realizar registro mediante Shared Preferences y
verificar mediante una vista de Longin de Usuario con una vista de apertura tipo
home.

Es un proyecto a utilizar como plantilla para una simple app de muestra de datos de 
productos a usuarios.

_Arquitectura:_
- Basado en Activitys.
